Classic tabular form: deflection angle θ down the rows, wave (shock) angle θ_w across the columns. Blank/faded cells mean that combination has no physical solution. Computed for γ=1.4 using the same closed-form relations as the reference script.

tan θ = 2·cotβ·(M₁²sin²β − 1) / (M₁²(γ + cos2β) + 2)

M₁ₙ = M₁sinβ · M₂ = M₂ₙ/sin(β−θ) · p₂/p₁ = 1 + (2γ/(γ+1))(M₁ₙ²−1) · ρ₂/ρ₁ = (γ+1)M₁ₙ²/((γ−1)M₁ₙ²+2), with γ = 1.4.
